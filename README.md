# Россия: регион за регионом

Отчёты о поездках по регионам России. Сайт: https://ssveretennikov.github.io/russia/

- `index.html` — общий пост со списком регионов по федеральным округам.
- `<код>-<имя>/` — страница региона, её фото и обложки роликов (`media/`).
- Ролики лежат в отдельном репозитории [ssveretennikov/russia-video](https://github.com/ssveretennikov/russia-video) и открываются по адресу `https://ssveretennikov.github.io/russia-video/<код>-<имя>/<ролик>.mp4`: GitHub Pages даёт 1 ГБ на сайт, а видео одно занимает почти столько же. Локально это папка `russia-video/` внутри проекта (свой git, в этот репозиторий не входит). В `src/*.html` адрес ролика пишется как `media/имя.mp4`, сборка заменяет его сама; для проверки до выкладки `python build.py --local-video` пишет рядом с каждой страницей `index.local.html` с роликами из локальной папки (в git он не идёт, страницы сайта при этом не меняются). Выкладывать сначала ролики (`git push` в `russia-video`), потом страницы.
- `src/` — тексты регионов, из которых собираются страницы.
- `regions/` — рабочие материалы (досье, отбор кадров, таблицы архива): закрытый репозиторий [ssveretennikov/russia-regions](https://github.com/ssveretennikov/russia-regions), локально это папка внутри проекта со своим git; в сайт не входит.
- `build.py` — сборка: `python build.py`.
- `tools/media.py` — подготовка фото и видео из архива.
- `tools/thumbs.py` — миниатюры для главной (`<код>-<имя>/thumb.webp`, 360×270) из главного кадра региона; делает недостающие и устаревшие, `--force` — все заново. Регион без миниатюры показывается на главной без фото.
- `series.css`, `series.js` — общее оформление.
- `fonts/` — шрифты Unbounded, Golos Text и Oswald (переменные WOFF2, кириллица и латиница) с лицензиями OFL; взяты с Google Fonts 05.10.2026, подключаются в начале `series.css`. Внешних шрифтов сайт не грузит.

## Карта на главной

`data/map.json` — контуры регионов для карты (делает `python tools/map.py путь/к/regions_with_dates_updated.geojson`, нужен numpy). Страница собирается в `build.py`, поведение карты и фильтров — в `map.js`. Новый посещённый регион появляется на карте автоматически, если он есть в GeoJSON и в списке `D` в `build.py`.

`data/transport.json` — как Сергей впервые приехал в регион (car, bus, plane, train, other). Используется в анимации «Показать путь» и в карточке региона.
