# Россия: регион за регионом

Отчёты о поездках по регионам России. Сайт: https://ssveretennikov.github.io/russia/

- `index.html` — общий пост со списком регионов по федеральным округам.
- `<код>-<имя>/` — страница региона и её фото и видео (`media/`).
- `src/` — тексты регионов, из которых собираются страницы.
- `build.py` — сборка: `python build.py`.
- `tools/media.py` — подготовка фото и видео из архива.
- `series.css`, `series.js` — общее оформление.
